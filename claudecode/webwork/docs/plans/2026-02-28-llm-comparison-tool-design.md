# 多平台LLM聚合对比工具 - 设计方案

## 项目概述

创建一个MCP Server工具，可以同时通过千问(Kimi)、Kimi、Minimax和智谱AI四个大模型网页平台回答问题，收集结果并进行对比分析。

## 核心模块

### 1. MCP Server
- 提供tools和resources
- 处理请求分发
- 支持两种使用方式：MCP调用 + 网页界面

### 2. 浏览器池管理器
- 管理4个平台各自的浏览器实例/会话
- 隔离各平台的登录状态

### 3. Cookie管理器
- 自动读取Cookie（优先）
- 读取失败时提示用户手动登录
- 保存/复用Cookie

### 4. 任务调度器
- 同时向4个平台发送问题
- 并行执行提高效率

### 5. 结果收集器
- 获取各平台原始回复
- 统一格式返回

### 6. 对比分析器
- AI评估回答质量
- 分析结论一致性/差异性

## 功能流程

1. **启动**: 初始化浏览器池，加载Cookie
2. **登录**: 优先读取Cookie，失败则提示用户手动登录
3. **输入**: 用户输入问题
4. **并行请求**: 同时向4个平台发送问题
5. **结果收集**: 获取各平台原始回复
6. **展示**: 并排显示原始回复
7. **对比分析**: AI评分 + 质量/一致性对比表格

## 技术选型

- **MCP Server**: Python + FastMCP
- **浏览器自动化**: Playwright
- **网页前端**: 简单HTML + JavaScript
- **AI评估**: 使用其中一个平台的API进行评估
